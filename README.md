# 時間軸小工具

用來整理角色、世界觀與各種設定的時間軸工具，原創作品、二次創作、歷史人物或任何需要按時間整理的內容都適用。可以把人物的生平事件、世界大事、時代分期排在同一條時間軸上，並記錄人物資料、人物關係、組織與設定集。

## 開始使用

先選擇你要用哪一種版本：

| | 線上版 | 電腦離線版 |
|---|---|---|
| 適用裝置 | 手機、平板、電腦 | 僅電腦 |
| 是否需要網路 | 開啟時需要 | 不需要 |
| 開啟方式 | 點網址 | 雙擊下載的檔案 |

### 線上版（手機、平板、電腦）

1. 點本頁右上角的 **網站連結**（About 區塊中的 Website），或直接開啟專案提供的網址。
2. 開啟後即可使用，無須安裝或註冊。

**手機加入主畫面（之後點圖示就能開）：**

- iPhone（Safari）：點下方的「分享」圖示 → 「加入主畫面」。
- Android（Chrome）：點右上角「⋮」→ 「加到主畫面」或「安裝應用程式」。

### 電腦離線版

1. 用電腦開啟線上版網址。
2. 按首頁右上角的 **下載電腦離線版**。
3. 下載後雙擊檔案，會以瀏覽器開啟，之後不需要網路。

> 手機無法開啟離線檔案，請使用線上版。

第一次開啟時會附上範例世界觀「偉大世紀（範例）」，可以先瀏覽了解功能，不需要時可於該世界觀的「設定」中刪除。

## 主要功能

- **時間軸**：依年份排列角色事件；同一時間的事件會並列顯示，可標記重大事件。
- **世界大事與時代分期**：記錄影響所有角色的事件，以及以年份劃分的時代。
- **角色檔案**：記錄出生、去世、自訂資料欄位、簡介、頭貼與家族關係。
- **關係圖、系譜與組織圖**：以圖表檢視角色之間的關係、家族與組織架構。
- **設定集**：記錄地點、組織、物品、名詞等設定，並可在事件中互相連結。
- **矛盾檢查**：自動找出時間或設定上的衝突，例如角色在出生前就出現在事件中。
- **輸出**：可輸出為圖片（分頁或長圖）及可列印的設定書。
- **外觀**：提供多組配色、背景樣式與自訂配色；每個世界觀可設定專屬外觀與圖示。

## 基本操作

1. 在首頁選擇或新增世界觀。
2. 進入世界觀後，將右上角切換為「編輯」，即可新增角色與事件。所有修改都會自動儲存。
3. 按右上角的「說明」可隨時查看介面導覽。

## 與他人分享

本工具沒有帳號系統，資料不會上傳至任何伺服器。要分享內容時：

1. 在世界觀中按「匯出／匯入」，複製代碼（或存成檔案）傳給對方。
2. 對方在首頁按「匯入世界觀」，貼上代碼即可看到相同內容。

匯出時可選填作者名稱，也可以將世界觀設為唯讀。

- 未設為唯讀時，對方匯入後可以在其裝置上修改；對方的修改不會影響您這邊的資料。
- 唯讀設定僅限制於本工具內編輯，並非加密保護。
